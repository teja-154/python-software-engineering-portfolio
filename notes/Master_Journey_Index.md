## 💡 Core Engineering Principles Burned Into Memory
1. **No Code Dumping**: You write your own code to build muscle memory; Hermes provides logic frameworks, explanations, and safety reviews.
2. **Defensive Programming**: Always account for missing files, incorrect input types, empty datasets, and boundary checks (`try...except`, `.is_file()`, `.is_dir()`).
3. **Trace & Verify**: Never trust that code works until you test edge cases (empty files, missing inputs, wrong types) and verify outputs manually.
